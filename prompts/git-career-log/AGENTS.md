# git-career-log

Development conventions for the `git-career-log` prompt.

## Versioning

Bump `VERSION.md` and add a `CHANGELOG.md` entry for any change to `PROMPT.md` that alters the workflow, output format, or edge case handling. Patch for fixes, minor for new steps or output sections, major for breaking changes to the output format.

## Language

Follow the root `AGENTS.md` language rules: Oxford British English in prose, American English in code and identifiers.
