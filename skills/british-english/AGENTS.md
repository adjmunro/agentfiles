# british-english — Agent Instructions

## Versioning

This skill uses semantic versioning in `VERSION.md`.

- **Patch** (`x.x.N`): additions to the substitution word list
- **Minor** (`x.N.0`): new file-type support, new skip rules, new flags
- **Major** (`N.0.0`): breaking changes to behaviour or output format

Only bump the version when changes are scoped to `skills/british-english/`.

## Conventional Commits

Use conventional commits for all changes to this skill:

```
feat(british-english): short description
fix(british-english): short description
refactor(british-english): short description
docs(british-english): short description
chore(british-english): short description
```

**Never force push.**

## Changelog

Keep `CHANGELOG.md` up to date. Most recent version at the top.
